# ACG 日语词典内容生产风格指南 v0.1

## 核心原则
1. 面向中文母语者解释日语语义和语感。
2. 明确区分现实日语与 ACG/二次元语境。
3. 例句必须以原创教学句为主，不直接搬运知名台词。
4. LLM 只用于离线内容生产与审计。
5. 优先准确，其次再追求二次元风格感。

## 解释要求
- 使用简体中文
- 说清词义、语感、误区、现实使用场景
- 不要只给生硬翻译

## 例句要求
- `daily`：现实自然表达
- `acg`：有风格但保持原创，不复刻名台词

## 审计重点
- 词义是否偏离
- 中文解释是否适合中文母语者
- 例句是否自然
- 是否疑似版权风险
